TRUE GAMING MONGOLIA — CS2 SKIN CATALOG

Хийгдсэн:
- Rifles / Pistols / SMGs / Heavy / Knives / Gloves үндсэн ангиллууд
- Зэвсгийн загвар > skin finish > wear + float хүрээ
- CS2 item мэдээлэл, зураг: ByMykel/CSGO-API (интернэтээс)
- Steam Market үнэ: Node.js server.js дээрх API proxy; Steam хязгаарлавал үнэ гарахгүй.
- Facebook: https://www.facebook.com/TrueGamingMongolians
- Сайт дээр захиалга, мөнгө шилжүүлэг, Steam нэвтрэлт байхгүй.

КОМПЬЮТЕР ДЭЭР ШАЛГАХ:
1. Node.js 20+ суулгана.
2. Файлууд байгаа хавтсыг terminal дээр нээнэ.
3. npm start
4. http://localhost:3000 дээр орно.

НИЙТЭД НЭЭЛТТЭЙ САЙТ БОЛГОХ (Render):
1. Эдгээр файлыг GitHub repository-д оруулна (index.html, server.js, package.json, render.yaml).
2. https://dashboard.render.com/ => New => Web Service => GitHub repository-гаа сонгоно.
3. Runtime Node, Build: npm install, Start: npm start, plan Free (боломжтой үед).
4. Deploy дууссаны дараа Render-ээс <service>.onrender.com гэсэн URL өгнө.
5. Тэр URL-ээ Facebook Page-ийн auto reply дээр тавина.

АНХААРАХ:
- Steam Market нь зохистой давтамжаар хязгаарлагддаг. Үнийн API нь 1 цаг cache, 3 секундын throttle-тэй; зарим үнийн хүсэлт амжилтгүй байж болно.
- Хэрэв байнгын live үнэ бүх хэрэглэгчид шаардлагатай бол лицензтэй өгөгдөл нийлүүлэгч хэрэгтэй.
- Live худалдааны захиалга болон төлбөрийн API-г сайт боловсруулдаггүй.
- Үндсэн CS2 skin мэдээллийн эх сурвалж нь албан бус. Эх сурвалжийн лиценз, үйлчилгээний нөхцөлийг шалгаарай.
